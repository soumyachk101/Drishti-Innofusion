1. Error envelope

All errors (except auth middleware) return:

JSON 
{
 "error": {
 "type": "string",
 "title": "Human-readable summary",
 "status": 400,
 "detail": "Detailed message",
 "instance": "Optional context"
 }
}

Status codes: standard_http (400, 401, 403, 404, 422, 409, 413, 429, 500).

6. Middleware stack (order)

  1. MaxBodySizeMiddleware — ASGI streaming body cap (1 MB)
  2. TimingMiddleware — Adds X-Process-Time header
  3. RateLimitMiddleware — Token bucket (per-group keying)
  4. AuthMiddleware — JWT or agent-token parsing
  5. CORSMiddleware — Allowlist
